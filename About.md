## Who we are

DeveloperHCR turns curiosity into practical experiments — from developer tools and Android experiences to responsive web products. We focus on clear interfaces, useful details, and technology that feels approachable.

Our work combines product thinking, practical engineering, and continuous learning to create software that is useful from day one.

## Mission and vision

- **Mission:** Make technology more valuable, productive, and approachable by creating software that feels useful for real users.
- **Vision:** Build accessible, polished digital experiences that connect engineering, design, and innovation.
- **Approach:** Design lean systems, test ideas quickly, and refine them through feedback and practical implementation.

## What we focus on

- **AI-assisted software & developer workflows** — tools and experiments that help people build, learn, and work more clearly.
- **Android applications & desktop-style experiences** — app and virtual-desktop concepts with practical UX.
- **Responsive websites & digital products** — premium, accessible static/web experiences with clear product storytelling.
- **Productivity tools** — systems designed for clarity, speed, and real-world usefulness.

## Projects and ecosystem

### HCRAPP
AI-assisted developer workspace project focused on coding tools, file management, virtual desktop concepts, utilities, and productivity features.

- Repository: [github.com/DeveloperHCR/HCRAPP](https://github.com/DeveloperHCR/HCRAPP)

### DevX OS
A computer-style graphical desktop environment concept for Android featuring a custom desktop GUI, window management, and file-system ideas.

- Browser demo (website simulation): [DevX OS Demo](https://developerhcr.github.io/HCRAPP/pages/devx-os-demo.html)
- Stable Android release: [DevXOS-3.0 (stable)](https://github.com/DeveloperHCR/HCRAPP/releases/tag/DevXOS-3.0(stable))
- Direct APK: [DevXOS3.0.apk](https://github.com/DeveloperHCR/HCRAPP/releases/download/DevXOS-3.0(stable)/DevXOS3.0.apk)

> The browser demo is an interactive website simulation (Files, Notes, Settings, Admin Panel sample, Calculator, Calendar, local-only sample Browser, simulated Terminal, sample System Monitor, About). It is not the Android app or a real operating system; it does not persist data, access system resources, or send data.

### DevX Billing
Browser-based shop and invoice management concept with product, customer, payment history, and reporting sections.

- Live demo: [developerhcr.github.io/DevX_Billing](https://developerhcr.github.io/DevX_Billing/)
- Repository: [github.com/DeveloperHCR/DevX_Billing](https://github.com/DeveloperHCR/DevX_Billing)
- Release: [DevX_billing_1.3.2](https://github.com/DeveloperHCR/DevX_Billing/releases/tag/DevX_billing_1.3.2)

> Use sample information only in demos. The embedded preview is sandboxed and does not persist data; the standalone app may store data/credentials in browser local storage on the `developerhcr.github.io` origin.

### DeveloperHCR Engine
The site’s first page (`pages/search.html`) provides a DeveloperHCR-branded engine experience with unlimited web search, full-screen on-site results, on-device AI (limited per browser profile, unlimited for admin when signed in locally), multi-style themes, local Chrome/Google-style sign-in (no cloud), local profile/device info, and quick access to inner and outer pages.

- Engine: [developerhcr.github.io/HCRAPP/pages/search.html](https://developerhcr.github.io/HCRAPP/pages/search.html)

## Website

The DeveloperHCR website in this repository is a static HTML/JavaScript project (styles embedded in pages) designed for GitHub Pages with no build step. The root GitHub Pages URL opens the DeveloperHCR Engine first.

**Main pages:** Engine (default landing), Home, About, Projects, Services, AI & API, Downloads, Documentation, Gallery, Contact, Privacy, Terms.

- Website: [developerhcr.github.io/HCRAPP](https://developerhcr.github.io/HCRAPP/)
- Website About page: [pages/about.html](https://developerhcr.github.io/HCRAPP/pages/about.html)

Features include English/Hindi/Hinglish support, lightweight navigation/language/UI scripts, a contact flow that opens a prefilled email in the visitor’s email app (no server-side form storage), and local-only demo/admin/status UI on static pages where applicable.
